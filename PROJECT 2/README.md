EXPENSE TRACKER

PROJECT OVERVIEW:

The Expense Tracker is a simple Python-based application that allows users to enter multiple expenses and calculate the total amount spent.

The program accepts expense amounts one by one, adds each amount to the running total, and displays the final total when the user finishes entering expenses. The project demonstrates fundamental programming concepts such as variables, arithmetic operations, loops, user input, accumulators, and exception handling.

OBJECTIVE:

The main objective of this project is to develop a simple expense calculation program and understand how values can be continuously collected and processed using Python.

FEATURES:

Enter multiple expense amounts.
Automatically calculate the total expenses.
Stop entering expenses by entering 0.
Prevent negative expense values.
Handle invalid inputs.
Display the final amount spent.
Technologies Used
Programming Language: Python
Development Environment: Visual Studio Code
Interface: Command Line / Terminal

HOW THE PROGRAM WORKS"

The program starts and displays the Expense Tracker interface.
The user enters an expense amount.
The entered amount is added to the running total.
The user can continue entering additional expenses.
Entering 0 ends the expense-entry process.
The program displays the total amount spent.

For example, if the user enters:

100
50
20
0

The program calculates:

100 + 50 + 20 = 170

and displays:

Total Spent: ₹170.00

CONCLUSION:

The Expense Tracker project demonstrates how Python can be used to process numerical data and perform basic calculations. It provides a practical understanding of accumulators, loops, input validation, and arithmetic operations through a simple expense management application.
